# enc_pass_B

개발 중.. 1일 1commit 예정..


### 간단 설명

사용자가 마스터 암호를 설정하면, 기존에 저장된 비밀번호들을 암호화하여 Windows 레지스트리에 저장합니다. 이후 추가하는 비밀번호도 암호화하여 저장합니다.

마스터 암호를 설정한 이후에는 암호관리자를 실행할 때마다 마스터 암호를 입력해야 합니다. 입력한 마스터 암호로 비밀번호를 복호화하는 데 필요한 키를 생성하고, 이를 이용해 레지스트리에 저장된 비밀번호들을 복호화하여 암호 관리자에서 사용할 수 있도록 합니다.

마스터 암호와 이를 통해 생성된 암호화·복호화 키는 레지스트리에 저장하지 않습니다. 대신 키 생성에 필요한 일부 설정값(공개해도 되는 값)을 저장하여, 사용자가 마스터 암호를 입력했을 때 언제든 동일한 키를 다시 생성할 수 있도록 합니다.
